# CodeGym Career - Material Design Landing Page

**Sinh viên:** Trần Thanh Tú

## Mục tiêu
Thiết kế lại Landing Page CodeGym Career theo phong cách Material Design, sử dụng:
- HTML5
- CSS3
- JavaScript / jQuery
- Bootstrap 4.5
- MDBootstrap 4.19.1
- Font Awesome
- Google Fonts Roboto

## Cấu trúc
- `index.html`: nội dung và cấu trúc trang
- `style.css`: giao diện tùy chỉnh và responsive
- `script.js`: smooth scroll và xử lý form demo

## Các phần giao diện
1. Navbar responsive
2. Hero / CTA
3. Tổng quan chương trình
4. Lợi ích CodeGym Career
5. Lộ trình Coding Bootcamp
6. Khóa học CGC Java / CGC PHP
7. Trải nghiệm học tập
8. Testimonial carousel
9. Form đăng ký tư vấn
10. Footer

## Chạy dự án
Mở `index.html` bằng Chrome/Edge. Cần Internet để tải các thư viện CDN.
